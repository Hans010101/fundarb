# ADR 0001：公开雷达与实盘执行面分离

- 状态：已采纳
- 日期：2026-08-08

## 背景

跨交易所资金费率套利需要固定出口 IP、交易所 API 白名单、双腿状态机、崩溃对账，以及在主引擎失效时仍可独立平仓的风控进程。Cloudflare Workers 是共享边缘运行时，出口地址不固定。

## 决策

1. Cloudflare 仅承载公开市场扫描、费率归一化、成本模型与只读看板。
2. 公开部署不接收 API Key、不保存账户信息、不提供下单接口。
3. 未来执行器部署到固定出口 IP 的独立主机，使用独立子账户、禁提现、IP 白名单和独立 engine/risk 密钥。
4. 默认路径依次为 market-data → paper → testnet → 小额 live；每一阶段需要人工 go/no-go。
5. 任何下单超时都归为状态不明，不得盲目重发；必须使用 clientOrderId 查询真实状态。

## 理由

这是把“点金手”的边缘市场数据经验复用到新项目，同时避免将其不适用于双腿套利的 serverless 执行路径照搬过来。公开仓库与公开站点也不应包含策略账户、额度、白名单或交易密钥。
