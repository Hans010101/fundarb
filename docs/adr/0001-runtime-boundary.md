# ADR 0001：公开应用、密钥控制面与固定出口执行面分离

- 状态：已采纳
- 日期：2026-08-08

## 背景

跨交易所资金费率套利需要固定出口 IP、交易所 API 白名单、双腿状态机、崩溃对账，以及在主引擎失效时仍可独立平仓的风控进程。Cloudflare Workers 是共享边缘运行时，出口地址不固定。

## 决策

1. Cloudflare 承载公开市场扫描、前端、管理鉴权、风控总闸、交易意图账本和加密凭证库。
2. 交易所密钥只以 AES-256-GCM 密文写入 D1；加密主密钥、管理凭证和中继凭证只存在 Cloudflare Secret，公开仓库和浏览器均不回显 Secret。
3. 实际访问交易所的网络请求必须经过固定出口 IP 的独立中继；中继不保存交易所密钥，只接受 Worker 已签名且命中主机/路径/方法/请求头白名单的短请求。
4. 使用独立子账户、禁提现、IP 白名单和独立密钥。固定主机后续还要承载持续对账与独立风险守护进程。
5. 默认路径依次为 market-data → paper → testnet → 小额 live；每一阶段需要人工 go/no-go。
6. 任何下单超时都归为状态不明，不得盲目重发；必须使用 clientOrderId 查询真实状态。

## 理由

这是把“点金手”的 Cloudflare 控制面与密钥隔离经验复用到新项目，同时补上跨所双腿交易所需的固定出口边界。Cloudflare 负责授权和持久化，固定主机负责受限网络出口；任何一侧单独失陷都不能同时得到明文长期密钥和任意网络代理能力。
